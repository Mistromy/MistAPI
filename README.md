# MistAPI
Unified API for all my stuff

# Public:
### [Nirupama](https://api.mista.tech/nirupama):

| name               | description                              |
|--------------------|------------------------------------------|
| messages_tracked   | total messages tracked by the bot        |
| guild_count        | total servers the bot is in              |
| user_count         | total users across all servers           |
| uptime             | uptime of the bot, fetched from cronitor |
| epoch_ms           | epoch of last message tracked            |
| heartbeat_epoch_ms | epoch of last heartbeat                  |
