# Artstation

**User's List of Projects:**  
`https://www.artstation.com/users/{username}/projects.json?page=1`  
**Specific Project**  
`https://www.artstation.com/projects/{hash_id}.json`

### Projects Entries
id, slug, user_id, title, description, created-at, updated_at
